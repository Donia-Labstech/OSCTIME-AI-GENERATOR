## 📖 عن المشروع

**DONIA-LABS-OSCTIME-AI-GENERATOR** هو تطبيق ويب احترافي يعتمد على الذكاء الاصطناعي **DeepSeek** لتحليل بيانات الإسناد التربوي، وتحويلها تلقائياً إلى ملفات **XML** جاهزة للاستيراد المباشر في **aSc Timetables 2023 (osctime)**.

## ✨ المميزات

- 📊 رفع ملفات Excel (.xlsx / .xls / .csv)
- 🤖 تحليل النصوص العربية بالذكاء الاصطناعي
- 🧩 نظام إدخال متعدد (Wizard + Excel + Free Text)
- ⚙️ محرك XML محلي (Fallback) بدون إنترنت
- 🎯 توافق 100% مع osctime 2023
- 🔐 تخزين آمن لمفتاح API في المتصفح
- 🌐 واجهة عربية RTL احترافية

## 🧰 المتطلبات

- متصفح حديث (Chrome / Firefox / Edge)
- مفتاح DeepSeek API — [platform.deepseek.com](https://platform.deepseek.com/)
- برنامج aSc Timetables 2023
